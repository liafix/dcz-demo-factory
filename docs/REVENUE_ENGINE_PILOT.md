### Gmail draft adapter — disabled by default

\`\`\`sh
python -m factory.worker --stage draft --input /path/to/private-verified-lead.json --url https://dcz-demo-factory.vercel.app/demos/verified-client/
\`\`\`

This is for a separately QA-approved, externally accessible URL. It validates the URL and rejects protected, non-200, or non-noindex pages. It never sends a message. Gmail requires \`GMAIL_ACCESS_TOKEN\` or the OAuth \`GMAIL_CLIENT_ID\`, \`GMAIL_CLIENT_SECRET\`, \`GMAIL_REFRESH_TOKEN\` variables, obtained through consented Google authorization with minimal draft scopes. Store secrets in an authorized secret manager, never a committed file. Gmail adapter checks existing draft headers across pages before creating one, then reads back the created draft ID. Phone/IG/FB fallback is a manual message, not a sending capability.

**No live draft has been executed through this pilot code.** Vercel READY, automated browser QA and Airtable persistence are not implemented here. Do not treat a local render or HTTP 200 as customer-ready.
